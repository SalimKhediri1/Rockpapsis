# Rockpapsis

A simple Rock Paper Scissors game built with plain HTML, CSS, and JavaScript.

This project started as a basic The Odin Project exercise and now has a more playful interface while keeping the code beginner-friendly.

## Features

- First player to 5 points wins
- Modern responsive layout
- Animated Rock, Paper, and Scissors buttons
- Separate score cards for the player and computer
- Clear round feedback for wins, losses, and ties
- Round history
- Play again button after the game ends

## Files

- `index.html` contains the page structure
- `styles.css` contains the visual design and responsive styling
- `java.js` contains the game logic

## How to run

Open `index.html` in your browser.

No build step, framework, or dependencies are required.

## How to play

Choose Rock, Paper, or Scissors. The computer will pick a random move. The first side to reach 5 points wins the game.
